## Product hierarchy

**Master brand:** Atlas SI / AtlasHub.SI.  
**Architecture:** Atlas Harness.  
**User-facing agent workspace:** AtlasBot (candidate runtime, internal pilot).  
**Runtime:** Atlas-Agent / Hermes ACP.  
**Pillars:** Workforce, Memory Fabric, Operational Knowledge, WorkSwarms (R&D), CRM-OS (BU).

**Recommendation:** no separate social accounts for each repository. Launch one coherent Atlas SI brand presence using the current AtlasHub and executive professional channels; reserve AtlasBot/Atlas Harness handles only if a product-specific community and content cadence justify the operational overhead. Keep GWD's distinct consumer/community positioning separate.

## Claim standards

- **Publicly verifiable today:** `https://www.atlas-si.com/pt`, 4-language architecture preview, public source blueprint and early-access contact.
- **Internal evaluation:** Windows Desktop, private VPS remote host and Hermes ACP integration; publish demo evidence only after success.
- **Roadmap only:** public installers, client cloud editions, enterprise billing, multi-tenant access, independent Account API + Signal/TURN and open-source edition.
- **No commercial distribution claims:** desktop candidate derives from PolyForm Noncommercial OpenBot until usage rights or independent implementation are established.
- **No claims that AI already controls real customer operations** without execution evidence and permission.
